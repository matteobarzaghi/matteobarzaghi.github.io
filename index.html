Progetti

  1. Load test WebSocket per notifiche push — JMeter, Groovy, Bash

    GitHub

    Progetto per un cliente, reso anonimo e pubblicato come portfolio: notifiche push a terminali di pagamento e sul campo connessi in WSS.

    • Test plan JMeter 5.6.3 in cui ogni thread simula un terminale: connessione WSS, autenticazione JWT (AUTH/AUTH_OK), keep-alive PING/PONG.
    • Flusso end-to-end: comandi via HTTP POST e verifica della consegna push al terminale corretto, con misura della latenza POST→WAKE.
    • Macchina a stati per terminale in Groovy (JSR223), contatori condivisi tra thread, criterio pass/fail automatico sulla soglia di messaggi persi.
    • Profilo di carico parametrico (ramp-up, gradini, plateau, riconnessione), esecuzione non-GUI distribuita su più injector con dashboard HTML.
    • Script Bash per il tuning degli injector Linux a migliaia di connessioni simultanee (file descriptor, porte effimere, TIME_WAIT, conntrack, buffer) e setup idempotente delle VM.
    • Configurazione esterna senza credenziali nel codice, secret scanning con gitleaks prima della pubblicazione.
